# Front-end Pro — Hillel IT School (2025)

This repository contains my coursework from **Hillel IT School's Front-end Pro course (May–September 2025)**, which I completed with an **Excellent** evaluation.

It is a collection of individual JavaScript and React assignments, **not one deployable application**. The original task directories have been preserved so you can trace the progression of the course.

## Running an exercise

There is no shared root package or universal start command.

For a browser exercise, open its HTML file using a local static server. For tasks containing `package.json`, enter that task's directory, run `npm install`, and inspect its scripts before starting it. React/Vite tasks generally expose a `dev` script; backend and Webpack exercises have their own requirements.

## Scope

This repository is a learning archive demonstrating practice across JavaScript, browser APIs, frontend tooling, React, and state management. A standalone application, [Tool Fan Page](https://github.com/Phonker131/tool-fan-page), is presented separately.

Task names are preserved for traceability. Runtime behavior and test results have not been verified as part of this documentation update.
