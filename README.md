# Frontend Coursework — 2025

A collection of JavaScript and React learning exercises. Each task is kept in its original folder so the progression and assignment references remain easy to follow.

## Navigation
| Folder | Contents visible in the repository |
| --- | --- |
| `task1/`–`task18/` | JavaScript and browser exercises; some tasks have several subfolders |
| `task19/`–`task21/` | Exercises with package-based tooling; task21 includes Webpack and SCSS |
| `task22/` | Todo frontend and Node.js backend with a Todo model |
| `task23/`, `task25/`–`task28/` | React/Vite exercises; components, routing, and theme context |
| `task29/` | Redux counter and todo examples |
| `task30/` | SWAPI data and Redux state |
| `task31/` | Todo application with Redux Saga |
| `task32/` | Routed React application with SWAPI and todo pages |
| `task33/` | Todo application with test sources |

## Running an exercise
There is no shared root package or universal start command.

For a browser exercise, open its HTML file using a local static server. For tasks containing `package.json`, enter that task's directory, run `npm install`, and inspect its scripts before starting it. React/Vite tasks generally expose a `dev` script; backend and Webpack exercises have their own requirements.

## Scope
This repository is a coursework collection. Standalone applications such as [Tool Fan Page](https://github.com/Phonker131/tool-fan-page) are presented separately.

Task names are preserved for traceability. Runtime behavior and test results have not been verified as part of this documentation update.
